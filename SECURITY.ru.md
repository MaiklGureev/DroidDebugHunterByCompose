# Сообщения о проблемах безопасности

[English](SECURITY.md) | **Русский**

Не публикуйте реальные токены, cookies, тела запросов, логи устройства, сертификаты с закрытыми ключами и WireGuard-профили в issue или PR. Для воспроизведения используйте синтетические данные.

Для уязвимости используйте приватный канал GitHub Security Advisories репозитория, если он включён, или сначала свяжитесь с владельцем без раскрытия технических деталей в публичном issue. Укажите версию, сценарий, воздействие и минимальный обезличенный пример.

Приложение обрабатывает трафик и управляет выбранным Android-устройством. CA, ключи VPN и настройки сохраняются локально в пользовательском каталоге данных. Они не предназначены для публикации в исходном репозитории. Автоматическая подготовка утилит запускается только по явной команде пользователя.
