# DroidDebugHunter · Compose — руководство

[English](USAGE.en.md) | **Русский**

Приложение на Kotlin + Compose Desktop для Windows, macOS и Linux. Готовые сборки включают Java и не требуют установки системного JDK/JRE. При работе из исходников используйте JDK 17 и `gradlew run` / конфигурацию IDEA `desktop`. Подробности: [платформы](PLATFORMS.md).

## Начало работы

HAR можно анализировать сразу: Ctrl+O → выберите файл либо откройте синтетический пример из репозитория. Телефон, ADB и Python для этого не нужны.

Для Android откройте «Настройки → Инструменты», укажите ADB, Python 3.14 и каталог комплекта. Нажмите «Применить» и проверьте утилиты. Загрузка дополнительных компонентов запускается только по вашей команде. [Подготовка комплекта](DOWNLOADS.md).

Включите USB-отладку, подтвердите RSA-ключ на телефоне и выберите устройство в верхней панели. Для Android 11+ можно выполнить Wi-Fi-сопряжение с шестизначным кодом, затем подключиться к отдельному порту отладки. [Настройка Android](ANDROID_SETUP_GUIDE.md).

## Устройства и приложения

Экран «Устройства» содержит USB/Wi-Fi-подключение, проверку root и управление frida-server. Экран «Приложения» показывает пакеты текущего Android-профиля; обновите список и выберите цель. Поиск учитывает название, пакет, UID и App ID (`UID % 100000`, не PID). Если названия недоступны, остаются имена пакетов.

Операции адресуются выбранному serial и профилю. После смены профиля обновите приложения. Очистка данных и удаление требуют подтверждения. «С JDWP» означает Java-отладку debuggable APK, а не Frida. [ADB-инструменты](ADB_TOOLS.md).

## Захват трафика

На экране «Трафик» откройте настройку рядом с запуском, выберите режим и нажмите «Проверить готовность». Проверка не заменяет ручную установку CA, разрешение VPN или проверку реальных данных после старта.

| Режим | Требования и ограничения |
| --- | --- |
| HTTP(S)-прокси | ADB reverse, приложение использует системный прокси. Для HTTPS требуется доверие CA. Пакет/UID неизвестны. |
| Frida · OkHttp | OkHttp 3/4; root-сервер либо debuggable + run-as/JDWP + Gadget. |
| Frida · Native TLS | Доступные native TLS-функции выбранного процесса. HTTP/1 и HTTP/2; скрытые/статические функции и HTTP/3 могут быть недоступны. |
| VPN · WireGuard | WireGuard, UDP-доступ к компьютеру, профиль выбранного пакета и подтверждение Android VPN. HTTPS требует доверия CA. |

У Frida client/server/Gadget должна совпадать версия 17.26.2 и подходить ABI. VPN указывает пакет по allowlist профиля, а не определяет UID по сетевым пакетам. Не запускайте конкурирующие сессии для одного устройства. [Пошаговая подготовка](ANDROID_SETUP_GUIDE.md).

## Анализ запросов

Фильтры и сортировка работают с накопленным трафиком и HAR. Двойной щелчок, Enter или «Детали» открывают отдельное окно запроса; можно сравнивать несколько окон. Доступны заголовки, запрос, ответ, cURL и диагностика, если её передал движок. Окно получает последующие обновления своего запроса.

Тела: Auto, Text, JSON, HTML-текст, Image, HEX, Base64. Сохранение тела сохраняет захваченные байты; сохранение вида — отображаемый текст. Частичные тела отмечены явно. [Просмотр тел](BODY_VIEWER.md).

На вкладке cURL выберите PowerShell либо POSIX shell. Команда может содержать cookies, токены и тело запроса — проверьте её перед передачей. HAR-экспорт сохраняет видимые HTTP-запросы и сведения о частичном захвате; диагностический поток не становится выдуманным HTTP.

## Logcat

Экран «Logcat» работает через ADB без Python/Frida, отдельно от HTTP-захвата. Можно записывать систему или выбранный UID, выбирать буферы и историю, фильтровать текст/tag/уровень/PID/TID/UID. Ctrl/Shift выбирают несколько строк; Ctrl+C копирует их. Экспорт: TXT, CSV, JSONL. [Подробности](LOGCAT.md).

## Хранение и завершение

Переключение экранов сохраняет потоки; смена/потеря устройства их останавливает. Обычное закрытие отменяет операции, завершает собственные процессы и восстанавливает принадлежащие сессии proxy/ADB-настройки. Общий ADB-сервер не останавливается. После принудительного завершения проверьте Android-прокси и VPN вручную.

Данные: `%LOCALAPPDATA%\DroidDebugHunterCompose` (Windows), `~/Library/Application Support/DroidDebugHunterCompose` (macOS), `$XDG_DATA_HOME/DroidDebugHunterCompose` или `~/.local/share/DroidDebugHunterCompose` (Linux). CA/ключи сохраняются; «Сбросить CA и VPN…» создаёт резервную копию. Сертификаты и профили на телефоне удаляются вручную.

Количество записей и память ограничены. Старые данные вытесняются; перегрузка Logcat учитывается отдельно. Экспорт не восстанавливает удалённые/пропущенные записи.

Ctrl+O — HAR, Ctrl+K — команды, F1 — справка, Enter/двойной щелчок — детали, Esc — закрыть окно. На macOS также поддерживаются сочетания с ⌘.
