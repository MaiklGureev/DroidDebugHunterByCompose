# ADB-инструменты

Откройте экран **«Приложения»** после выбора устройства на экране «Устройства». Команды выполняются только для выбранного serial. Frida и Python для этих команд не нужны.

На экране «Приложения» обновите список кнопкой «↻ Приложения» и явно выберите строку слева. Поиск сразу фильтрует название, пакет, UID и App ID без учёта регистра. Список разделён на «Сторонние» и «Системные»; обе группы загружаются вместе. Первый найденный пакет автоматически не выбирается. Если фильтр скрывает выбранную строку, действия приложения отключаются.

Команды Wi-Fi, мобильных данных и диагностики всего устройства находятся на отдельном экране «Инструменты». Для них выбор приложения не нужен.

В заголовке указан Android-профиль. Запуск, остановка, очистка, удаление и разрешения адресуются этому профилю. Если активный профиль изменился на телефоне, обновите список: действие со старым списком будет отклонено.

Если удалось получить локализованное название, оно показано рядом с пакетом и участвует в поиске. Название не заменяет пакет: приложения с одинаковыми названиями остаются отдельными строками. В окнах результатов и подтверждениях видны название и пакет. «Сохранить…» в окне результата экспортирует весь вывод в TXT / UTF-8.

## Группы

| Группа | Действия |
| --- | --- |
| Приложение · запуск и процесс | Запустить, остановить через force-stop, перезапустить, запустить/перезапустить с Java/JDWP-отладкой. |
| Приложение · данные и удаление | Очистить данные, очистить и запустить, удалить приложение для выбранного профиля. |
| Приложение · runtime-разрешения | Загрузить объявленные опасные runtime-разрешения, выбрать одно, выдать или отозвать. |
| Приложение · диагностика | Информация о пакете и путях APK, PID/процессы, последние логи, открытие настроек приложения на Android. |
| Устройство · сеть | Включить/выключить Wi-Fi и мобильные данные, посмотреть IP/маршруты/прокси, открыть настройки Wi-Fi. |
| Устройство · диагностика | Android, SDK, ABI, модель, размер экрана и батарея; список процессов устройства. |

После выполнения действия результат или ошибка открываются в отдельном окне с названием команды, устройством и пакетом, если действие относится к приложению. «Копировать всё» копирует вывод, Esc закрывает окно. Каждое окно сохраняет свой результат: можно оставить несколько окон для сравнения и продолжать работать на основной вкладке. Обновление списков приложений и разрешений не открывает окна результатов. Журнал ADB находится в сворачиваемой нижней панели. «Отмена» отменяет текущую команду; уже выполненные действия на Android могут сохраниться.

## Запуск и отладчик

Для запуска определяется launcher-активность пакета. Если её нет, программа сообщает об этом; открыть такую службу как обычное приложение нельзя. При перезапуске сначала проверяется доступность launcher, затем выполняется force-stop и запуск.

«С отладчиком» означает **Java/JDWP**, требует debuggable APK и последующего подключения IDE/отладчика. Это не запуск Frida. Для уже работающего процесса используйте «Перезапустить с отладчиком». Обычные остановка и перезапуск могут прервать активный захват Frida этого процесса.

## Данные и удаление

Перед очисткой или удалением появляется подтверждение с устройством, профилем и полным пакетом. По умолчанию выбрано «Нет». Очистка удаляет данные и настройки, включая сохранённый вход в аккаунт. «Очистить и запустить» проверяет launcher до удаления и запускает приложение только после подтверждённого Android успешного удаления данных.

Удаление выполняется для выбранного Android-профиля, а не для всех пользователей. После успешного удаления пакет и его разрешения убираются из текущего выбора. Передумав, не подтверждайте действие: восстановить удалённые данные из этой вкладки нельзя.

## Разрешения

Выберите приложение → «Загрузить разрешения» → выберите разрешение → «Выдать» или «Отозвать». Статус читается для выбранного Android-профиля и обновляется после команды. Неизвестный статус показывается явно.

Список включает пересечение разрешений, объявленных пакетом, и опасных runtime-разрешений устройства. Обычные разрешения, signature-разрешения и специальные доступы вроде Accessibility/Draw over apps этим способом не выдаются. Android может отказать из-за SDK, политик, ограничений разрешения или прошивки; ошибка показывается в результате. Отзыв разрешения может завершить процесс приложения.

## Сеть и диагностика

Сетевые действия относятся ко всему выбранному устройству и не требуют пакета. При выключении Wi-Fi для беспроводного ADB появляется предупреждение о возможном разрыве связи. После разрыва используйте USB или восстановите Wi-Fi на самом устройстве. Мобильные данные требуют подходящего устройства/SIM и поддержки команды прошивкой; успешный вызов не гарантирует доступ в интернет.

«Последние логи» — конечный снимок logcat, до 200 строк на процесс, до восьми процессов выбранного пакета/UID. Программа не переключается на общий logcat, если нужный PID неизвестен. Изолированные процессы с другим UID в эту выборку не входят. Старые версии Android могут не поддерживать необходимые параметры ps/logcat.

Вывод может содержать данные приложения: проверьте его перед передачей другим людям. Вкладка не повышает права через su автоматически. На реальном телефоне доступность команд зависит от Android и прошивки.

Документация: [ADB / am / pm](https://developer.android.com/tools/adb), [logcat](https://developer.android.com/tools/logcat).
