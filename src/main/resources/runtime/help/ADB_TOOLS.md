# ADB-инструменты

[English](ADB_TOOLS.en.md) | **Русский**

Для этих операций нужен ADB; Python и Frida не требуются. Выберите устройство, затем на экране «Приложения» обновите список и выберите пакет текущего Android-профиля. Поиск учитывает название, пакет, UID и App ID. Если Android не разрешает читать названия, используйте пакет.

| Раздел | Операции |
| --- | --- |
| Запуск и процесс | Запуск, force-stop, перезапуск, запуск/перезапуск с Java/JDWP. |
| Данные | Очистка, очистка и запуск, удаление для выбранного профиля с подтверждением. |
| Разрешения | Чтение объявленных опасных runtime-разрешений, выдача и отзыв. |
| Диагностика приложения | Сведения/пути APK, процессы, последние логи, настройки приложения на Android. |
| Сеть и устройство | Wi-Fi/мобильные данные, IP/маршруты/прокси, настройки Wi-Fi, сведения Android и процессы. |

Сетевые и общие действия находятся на «ADB-инструменты» и не требуют выбора пакета. Доступность зависит от Android, прошивки и политики устройства. Root не запрашивается автоматически для обычных команд.

## Цель и подтверждение

Команды привязаны к serial, профилю и пакету; после смены профиля обновите список. Очистка удаляет данные/настройки приложения. Удаление относится к выбранному профилю. Перед подтверждением проверьте устройство и полный пакет. Отмена останавливает собственную команду, но не отменяет уже выполненные изменения Android.

Запуск требует launcher-активность. JDWP требует debuggable APK и подключения IDE/отладчика; это не запуск Frida. Перезапуск/force-stop могут завершить инструментируемый процесс и захват.

Выдача/отзыв касается опасных runtime-разрешений, объявленных приложением. Signature-разрешения и специальные доступы вроде Accessibility этим способом не выдаются. Android может отказать из-за SDK/политик; отзыв может завершить приложение.

## Результаты и файлы

Результат команды открывается в отдельном окне. «Копировать всё» и «Сохранить TXT» сохраняют полный вывод, Esc закрывает окно. Можно сравнивать несколько окон. «Последние логи» — конечный снимок процессов выбранного приложения, а не автоматический общий Logcat.

На «ADB-инструменты» доступны отправка/получение файла и установка APK. Используйте доступные Android-пути; доступ к приватным данным ограничен правами устройства. Выключение Wi-Fi может разорвать беспроводной ADB; восстановите сеть на телефоне или используйте USB.

Перед публикацией вывода удалите данные приложения и секреты. [Настройка подключения](ANDROID_SETUP_GUIDE.md), [потоковый Logcat](LOGCAT.md).
