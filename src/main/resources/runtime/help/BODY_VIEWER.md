# Просмотр и сохранение тел

[English](BODY_VIEWER.en.md) | **Русский**

На «Трафик» откройте запрос двойным щелчком, Enter или «Детали». Отдельное окно содержит «Запрос», «Ответ», cURL и доступную диагностику. Несколько окон позволяют сравнивать запросы и получают последующие события своего запроса. Esc закрывает окно.

| Вид | Результат |
| --- | --- |
| Auto | Предпросмотр распознанного изображения; для прочих данных — текст/форматирование JSON, когда возможно. |
| Text | Текстовое представление захваченных байтов; бинарные данные могут выглядеть нечитаемо. |
| JSON | Форматирование корректного JSON; при ошибке остаётся доступен текст. |
| HTML-текст | Текст после удаления скриптов/стилей и тегов; без браузерной вёрстки, JavaScript и сетевых загрузок. |
| Image | Предпросмотр поддерживаемого изображения; повреждённые/неподдерживаемые данные можно сохранить или просмотреть как Base64/HEX. |
| HEX | Смещения, шестнадцатеричные байты и печатные ASCII-символы. |
| Base64 | Захваченные байты в Base64. |

Предпросмотр изображения ограничен по размеру; это не меняет сохранённые байты. Например, `iVBORw0KGgo` — характерное начало PNG в Base64: используйте Image/Auto вместо чтения декодированных байтов как UTF-8.

«Сохранить тело» записывает точные доступные байты (Base64 декодируется); текстовые тела сохраняются в UTF-8. «Сохранить вид» сохраняет отображаемый текст. Переключение вида не меняет исходное тело или cURL. Копирование представления копирует текст или поддерживаемое изображение.

Неполное/недоступное тело помечено явно; имя файла для частичного тела содержит `.partial`. Сохранение не восстанавливает недостающие байты. cURL не создаётся для запроса с неполным телом, чтобы не повторить другой запрос вместо исходного.

Выберите PowerShell либо POSIX-формат на вкладке cURL. Проверьте URL, cookies, заголовки и тело перед запуском/передачей команды. [Руководство](USAGE.md).
