# Просмотр и сохранение тел запросов и ответов

На вкладке «Трафик» таблица запросов занимает всю ширину. Откройте запрос двойным щелчком, клавишей Enter, кнопкой «Детали ↗» или через контекстное меню. В отдельном окне есть вкладки «Запрос», «Ответ» и «cURL». Вкладка «Ответ» открыта по умолчанию. У тел запроса и ответа независимые переключатели представления; они работают для живого захвата и HAR.

Окно закреплено за конкретным запросом и получает его живые обновления. Можно открыть несколько запросов для сравнения; повторное открытие той же строки поднимает существующее окно. Фильтрация или очистка основной таблицы не закрывает уже открытые детали. После очистки таблицы удалённые записи больше не получают события захвата. Esc закрывает текущее окно; закрытие приложения закрывает все окна деталей.

| Вид | Отображение |
| --- | --- |
| Auto | Определяет изображение по сигнатуре, форматирует JSON, извлекает видимый текст HTML; остальные данные показывает как текст либо Base64. |
| Text | Исходный текст без форматирования. Для HTML видны теги и скрипты как обычный текст. Base64 с текстовыми байтами декодируется с учётом charset. Бинарные данные сохраняются в Base64. |
| JSON | Отступы и переносы строк. При ошибке JSON остаётся исходный текст с сообщением о позиции ошибки. |
| HTML · текст | Читаемый текст страницы с декодированными HTML-сущностями. Скрипты, стили и скрытые шаблоны пропускаются; JavaScript не выполняется, ссылки и внешние ресурсы не загружаются. Это текстовое представление, без браузерной вёрстки. |
| Image | Предпросмотр поддерживаемых Windows изображений: в частности PNG, JPEG, GIF и BMP. При повреждённом, обрезанном или неподдерживаемом изображении доступен Base64 и сохранение. WebP определяется, но предпросмотр зависит от установленного кодека. |
| HEX | Смещения, шестнадцатеричные байты и печатные ASCII-символы. Отображаются первые 16 КиБ, экспорт включает всё захваченное тело. |
| Base64 | Захваченные байты в Base64, без преобразования бинарного файла в текст. |

`iVBORw0KGgo…` в Base64 обычно начинается с PNG-сигнатуры. После декодирования это байты изображения, поэтому вывод их через UTF-8 даёт нечитаемые символы. Используйте Auto / Image или сохраните тело как `.png`.

«Сохранить тело…» сохраняет захваченное тело: Base64 декодируется в точные байты, текст сохраняется в UTF-8. Расширение предлагается по сигнатуре или Content-Type. Переключение вида не изменяет исходное тело и экспорт cURL. Частичный захват отмечается рядом с просмотром; имя предлагаемого файла содержит `.partial`.

Для сохранения форматированного JSON, HTML-текста, HEX или Base64 щёлкните «Сохранить…» правой кнопкой и выберите «Сохранить текст просмотра…». Сохраняется показанный текст в UTF-8; если просмотр ограничен по размеру, это именно отображаемый фрагмент. Обычное сохранение тела включает все доступные захваченные данные.

«Копировать вид» копирует текущий текст либо предпросмотр картинки. Предпросмотр больших изображений масштабируется; исходные байты остаются доступны через сохранение тела.

В окне результата ADB кнопка «Сохранить…» сохраняет полный снимок вывода в TXT / UTF-8.
