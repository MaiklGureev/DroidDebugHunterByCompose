Трафик взят из [examples/ui-demo.har](../../examples/ui-demo.har): двенадцать вымышленных запросов к зарезервированным доменам `example.test`. Имена пакетов, идентификаторы приложений, время и содержимое запросов демонстрационные. На снимках нет реальных Android-устройств, учётных данных или перехваченного трафика. Использовались отдельная папка данных приложения и тестовый ADB, возвращающий пустой список устройств.

Для обновления снимков используйте отдельную папку данных (`-Ddroiddebughunter.dataDir=...`) и отключите автообновление устройств. Импортируйте HAR, откройте вкладку «Ответ» первого запроса, покажите «Настройки → Полуавтоматическая настройка → Комплект Frida» и «Справка → ADB-инструменты». Сделайте снимки обоих языков интерфейса. Для иллюстраций не запускайте захват или установку инструментов и не показывайте личные пути либо идентификаторы устройств.
