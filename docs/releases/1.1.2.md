# DroidDebugHunter 1.1.2

**English** | [Русская документация / Release notes in Russian](https://github.com/MaiklGureev/DroidDebugHunterByCompose/blob/v1.1.2/docs/releases/1.1.2.ru.md)

This release adds English/Russian interface switching and a Markdown viewer for offline Help. Native packages include Java: **no system JDK/JRE is required**.

## Changes since 1.1.1

- Added English interface translations and immediate language switching in Settings → Interface language. The selected language is saved automatically and restored at the next launch; offline Help follows the selection.
- Added formatted Markdown in Help: headings, emphasis, lists, quotes, tables, code blocks with a copy button, clickable links and section navigation. Ordinary text wraps to fit the window.
- Added opening local Markdown files and Back navigation. Relative document links stay within the selected documentation folder; external web links open only when clicked. Raw HTML is displayed as text and remote images are not loaded.
- Renamed the Help topic “Body viewer” to “Request and response content” / «Содержимое запросов и ответов».
- Centralized dependency and plugin versions in `gradle/libs.versions.toml`, and added CommonMark with its BSD license notice.
- Extended tests for translations, language persistence, Markdown formatting, local links and document limits. Packaged-runtime checks also load the Markdown parser and verify saved language selection.

- **Windows:** install MSI, or extract the complete ZIP and run `DroidDebugHunterByCompose.exe`. Keep `app` and `runtime` beside the executable.
- **macOS:** choose the matching CPU architecture, copy the `.app` from DMG to Applications, or extract the complete portable archive.
- **Linux:** install DEB through the package manager, or extract the portable archive and run `./bin/DroidDebugHunterByCompose`. A graphical desktop is required.

Current builds are unsigned; macOS packages are not notarized. System security checks may restrict launching a downloaded application.

HAR analysis works immediately. For devices/live capture, configure ADB and Python 3.14 in Settings → Tools and explicitly prepare the required components. Public packages do not include an external Python interpreter, ADB, Frida binaries or WireGuard APK. Normal startup downloads nothing. Follow offline Help for CA trust, Frida and Android VPN consent.

## Validation and integrity

Four native CI runners build and test Windows x64, Linux x64, macOS arm64 and macOS x64. Checks cover Kotlin/Python tests, bundled Java startup, device selection, language persistence, Markdown parsing and shutdown. A separate CI check verifies the isolated development JAR.

Publication verifies all eight binaries against their source commit, version, size and SHA-256 before creating the release. `SHA256SUMS.txt` covers the release assets; `manifest-*.json` records platform, architecture and exact source commit. All packages are built from the commit tagged `v1.1.2`. The MIT License, third-party notices and first-run instructions in English/Russian are included in the portable archives and as separate downloads.
