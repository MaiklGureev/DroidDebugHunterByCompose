# DroidDebugHunter 1.1.2

[English](https://github.com/MaiklGureev/DroidDebugHunterByCompose/blob/v1.1.2/docs/releases/1.1.2.md) | **Русский**

Релиз добавляет переключение языка интерфейса и Markdown-просмотрщик встроенной справки. Java включена в нативные сборки: **системные JDK/JRE не требуются**.

## Изменения после 1.1.1

- Добавлен английский интерфейс и переключение русского/английского через «Настройки → Язык интерфейса». Выбор применяется сразу, автоматически сохраняется и восстанавливается после запуска. Справка следует выбранному языку.
- В справке отображается форматированный Markdown: заголовки, выделение, списки, цитаты, таблицы, блоки кода с копированием, ссылки и переходы к разделам. Обычный текст переносится по ширине окна.
- Добавлены открытие локальных Markdown-файлов и переход назад. Относительные ссылки ограничены выбранной папкой документации; внешние веб-ссылки открываются только по нажатию. HTML показывается как текст, удалённые изображения не загружаются.
- Раздел «Просмотр тел» переименован в «Содержимое запросов и ответов» / “Request and response content”.
- Зависимости и версии плагинов перенесены в `gradle/libs.versions.toml`. Добавлен CommonMark с уведомлением о BSD-лицензии.
- Расширены тесты переводов, сохранения языка, Markdown-форматирования, локальных ссылок и ограничений документов. Проверки готовых приложений загружают Markdown-парсер и проверяют сохранение языка.

- **Windows:** установите MSI либо распакуйте ZIP целиком и запустите `DroidDebugHunterByCompose.exe`. Сохраняйте `app` и `runtime` рядом с exe.
- **macOS:** выберите архитектуру, перенесите `.app` из DMG в Applications либо распакуйте переносимый архив целиком.
- **Linux:** установите DEB через менеджер пакетов либо распакуйте архив и запустите `./bin/DroidDebugHunterByCompose`. Нужна графическая среда рабочего стола.

Сборки пока без подписи издателя, macOS — без notarization. Системные проверки безопасности могут ограничивать запуск скачанного приложения.

HAR-просмотр работает сразу. Для телефона и живого захвата откройте «Настройки → Инструменты», укажите ADB, Python 3.14 и явно подготовьте нужные компоненты. Публичные сборки не содержат отдельный Python, ADB, Frida binaries или WireGuard APK. Обычный запуск ничего не скачивает. Установку/доверие CA, Frida и VPN на Android настройте по встроенной справке.

## Проверки и целостность

Четыре нативных CI runner собирают и тестируют Windows x64, Linux x64, macOS arm64 и macOS x64. Проверяются Kotlin/Python-тесты, запуск на встроенной Java, выбор устройства, сохранение языка, Markdown-парсер и завершение модели. Отдельная CI-проверка проверяет изолированную копию JAR при запуске из Gradle.

Перед публикацией проверяются исходный commit, версия, размер и SHA-256 всех восьми бинарных файлов. `SHA256SUMS.txt` содержит контрольные суммы; `manifest-*.json` — платформу, архитектуру и точный исходный commit. Все пакеты собраны из коммита тега `v1.1.2`. MIT-лицензия, уведомления о сторонних компонентах и инструкции первого запуска на русском/английском входят в переносимые архивы и доступны отдельными файлами.
