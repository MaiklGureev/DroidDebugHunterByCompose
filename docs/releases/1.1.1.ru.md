# DroidDebugHunter 1.1.1

[English](https://github.com/MaiklGureev/DroidDebugHunterByCompose/blob/v1.1.1/docs/releases/1.1.1.md) | **Русский**

Релиз включает исправление запуска при пересборке, MIT-лицензию и документацию на русском и английском. Java включена в нативные сборки: **системные JDK/JRE не требуются**.

## Изменения после 1.1.0

- Исправлен `NoClassDefFoundError` классов корутин при пересборке работающего приложения из IDEA/Gradle. Конфигурация `desktop` / задача `run` используют отдельную временную копию JAR до завершения процесса.
- Проверка запуска теперь выполняет выбор устройства и завершение модели на Swing dispatcher. Используются изолированные временные данные, без подключения к Android и изменения пользовательских настроек.
- Собственный код опубликован по [лицензии MIT](https://github.com/MaiklGureev/DroidDebugHunterByCompose/blob/v1.1.1/LICENSE). Сторонние компоненты сохраняют свои лицензии и уведомления.
- Основной язык документации репозитория — английский; ссылка на русский находится в шапке. Документы по платформам, архитектуре, разработке, безопасности и релизам доступны на двух языках.
- Встроенная справка обновлена под Compose и три ОС, устаревшие WPF/.NET-инструкции заменены. Восемь разделов справки доступны на русском и английском. Интерфейс приложения пока на русском.
- В переносимые архивы и отдельные файлы релиза включены `LICENSE`, `README-FIRST.md`, `README-FIRST.ru.md`, `THIRD_PARTY_NOTICES.md` и `THIRD_PARTY_NOTICES.ru.md`. Полные офлайн-руководства входят в приложение.

- **Windows:** установите MSI либо распакуйте ZIP целиком и запустите `DroidDebugHunterByCompose.exe`. Сохраняйте `app` и `runtime` рядом с exe.
- **macOS:** выберите архитектуру, перенесите `.app` из DMG в Applications либо распакуйте переносимый архив целиком.
- **Linux:** установите DEB через менеджер пакетов либо распакуйте архив и запустите `./bin/DroidDebugHunterByCompose`. Нужна графическая среда рабочего стола.

Сборки пока без подписи издателя, macOS — без notarization. Системные проверки безопасности могут ограничивать запуск скачанного приложения.

HAR-просмотр работает сразу. Для телефона и живого захвата откройте «Настройки → Инструменты», укажите ADB, Python 3.14 и явно подготовьте нужные компоненты. Публичные сборки не содержат отдельный Python, ADB, Frida binaries или WireGuard APK. Обычный запуск ничего не скачивает. Установку/доверие CA, Frida и VPN на Android настройте по встроенной справке.

## Проверки и целостность

Четыре нативных CI runner собирают и тестируют Windows x64, Linux x64, macOS arm64 и macOS x64. Проверяются Kotlin/Python-тесты, встроенная Java, выбор устройства и завершение модели. Отдельная CI-проверка подтверждает изолированный JAR для запуска из исходников.

Перед публикацией проверяются исходный commit, версия, размер и SHA-256 всех восьми бинарных файлов. `SHA256SUMS.txt` содержит контрольные суммы; `manifest-*.json` — платформу, архитектуру и точный исходный commit. Все пакеты собраны из коммита тега `v1.1.1`.
