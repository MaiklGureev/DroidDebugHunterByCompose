# DroidDebugHunter 1.1.4

**English** · [Русский](https://github.com/MaiklGureev/DroidDebugHunterByCompose/blob/v1.1.4/docs/releases/1.1.4.ru.md)

## Changes

- **Capture one Android app with WireGuard.** The generated VPN profile routes traffic for the selected package. On a USB-connected TECNO phone, capture received seven HTTP requests from Navigator. A control request from Chrome reached the test server directly and produced zero capture entries.
- **Clear capture scope.** The Traffic tab identifies the HTTP(S) system proxy as device-wide and links to WireGuard setup. WireGuard and Frida enable **Selected app only** by default. WireGuard now opens after a profile transfer through its resolved Android launcher activity.
- **Connection setup.** USB, Wi-Fi and emulator connections, capture prerequisites and tool settings are available on the Connection tab. Each tool shows the detected and requested versions and offers downloads or manual setup as applicable.
- **Tool compatibility.** ADB archives are checked against the host architecture. Linux ARM64 can use native ADB from the distribution or a compatible local archive. Intel macOS proxy setup can use a compatible local `cryptography` wheel.
- **Diagnostics.** The application records its version, startup environment and tool failures in a file. Settings can export or clear the application log.
- **Offline Help.** Back navigation keeps the correct Markdown document when the file was opened through an alternate path on Windows or macOS.
