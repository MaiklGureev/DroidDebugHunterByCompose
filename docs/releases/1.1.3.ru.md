# DroidDebugHunter 1.1.3

[English](https://github.com/MaiklGureev/DroidDebugHunterByCompose/blob/v1.1.3/docs/releases/1.1.3.md) | **Русский**

Релиз добавляет гибкую настройку инструментов, открытые варианты установки, проверку совместимости и прогресс загрузок. Java включена в нативные сборки: **системные JDK/JRE не требуются**.

## Изменения после 1.1.2

- Ручной, полуавтоматический и автоматический режимы, компоненты и способы установки Python показаны карточками, без выпадающих списков. Подготовка требует явного выбора; открытие настроек ничего не скачивает.
- Добавлены переносимый Python через закреплённый uv, venv на основе существующего Python и локальные пакеты через `pip --target`. Автоматический режим может пробовать другие способы и доступную для записи папку данных пользователя. Повышение привилегий, изменение системного PATH и установка системных пакетов не выполняются.
- Проверяются обнаруженные и целевые версии, пути к исполняемым файлам и модулям. Старые/новые версии разрешены с предупреждениями; server/Gadget Frida подбираются под активный клиент вместо жёстко заданной версии.
- Добавлены отдельная загрузка архивов/APK, общий комплект Frida client/server/Gadget, копирование ссылок выбранных версий, открытие папок размещения/кеша и инструкции по форматам файлов.
- При известном размере загрузки показываются байты и проценты; для других этапов — неопределённый индикатор и живой журнал установки. Доступны отмена запущенных приложением процессов, повторное использование кеша, локальные архивы и офлайн-wheelhouse.
- При запуске приложение пытается создать недостающие папки; есть кнопка повторной проверки. Сохранённый путь к отсутствующей папке не теряется. Ошибки доступа показываются предупреждениями. Структура для ручной настройки описана на русском и английском.
- Загрузки, ELF/ABI и импорты пакетов проверяются до активации. При неудачной подготовке пакетов прежняя установка сохраняется. Очистка резервных папок не следует по ссылкам на другие каталоги.
- В комплект Frida включены h11/hpack для отдельной работы декодера Native TLS. Frida и прокси используют разные пути Python-пакетов, чтобы не смешивать альтернативные версии зависимостей.
- В CI добавлена проверка загрузок из каждого готового приложения на встроенной Java со скрытой системной Java: создаётся собственный Python и проверяется ADB без подключения к Android.

Целевые версии: Python **3.14.10**, Platform Tools **37.0.3**, Frida **17.26.2**, frida-tools **14.13.1**, mitmproxy **12.3.1**, mitmproxy_rs **0.12.15**, необязательный WireGuard Android **1.0.20260315**, помощник установки uv **0.13.10**. Другие версии разрешены; учитываются зависимости, API и наличие wheels. Версии Frida client/server/Gadget должны совпадать между собой. Подробнее: [совместимость и настройка](https://github.com/MaiklGureev/DroidDebugHunterByCompose/blob/v1.1.3/src/main/resources/runtime/help/DOWNLOADS.md).

- **Windows:** установите MSI либо распакуйте ZIP целиком и запустите `DroidDebugHunterByCompose.exe`. Сохраняйте `app` и `runtime` рядом с exe.
- **macOS:** выберите архитектуру, перенесите `.app` из DMG в Applications либо распакуйте переносимый архив целиком.
- **Linux:** установите DEB через менеджер пакетов либо распакуйте архив и запустите `./bin/DroidDebugHunterByCompose`. Нужна графическая среда рабочего стола.

Сборки пока без подписи издателя, macOS — без notarization. Системные проверки безопасности могут ограничивать запуск скачанного приложения.

HAR-просмотр работает сразу. Для телефона и живого захвата откройте «Настройки → Инструменты», выберите вариант настройки, компоненты и способ установки Python либо укажите существующие исполняемые файлы. Загрузка требует явного нажатия кнопки. Публичные сборки не содержат отдельный Python, ADB, Frida binaries или WireGuard APK. Обычный запуск ничего не скачивает. Установку/доверие CA, Frida и VPN на Android настройте по встроенной справке.

## Проверки и целостность

Четыре нативных CI runner собирают и тестируют Windows x64, Linux x64, macOS arm64 и macOS x64. Проверяются 73 Kotlin-теста, 25 Python-тестов, встроенная Java, сохранение языка, Markdown, изолированный запуск из Gradle и настройка локальных инструментов. Проверки настройки используют встроенную Java со скрытыми путями системных JDK/JRE, проверяют собственный Python/ADB и прогресс загрузки без подключения к Android.

Перед публикацией проверяются исходный commit, версия, размер и SHA-256 всех восьми бинарных файлов. `SHA256SUMS.txt` содержит контрольные суммы; `manifest-*.json` — платформу, архитектуру и точный исходный commit. Все пакеты собраны из коммита тега `v1.1.3`. MIT-лицензия, уведомления о сторонних компонентах и инструкции первого запуска на русском/английском входят в переносимые архивы и доступны отдельными файлами.
