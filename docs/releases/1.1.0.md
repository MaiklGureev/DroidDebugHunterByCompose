# DroidDebugHunter 1.1.0

Android-отладчик на Kotlin + Compose Desktop: ADB, Frida, HTTP(S), HAR и Logcat.

## Какой файл скачать

| Система | Установщик | Без установки |
| --- | --- | --- |
| Windows 64-bit | `DroidDebugHunter-1.1.0-windows-x64.msi` | `DroidDebugHunter-1.1.0-windows-x64.zip` |
| macOS Apple Silicon (M1 и новее) | `DroidDebugHunter-1.1.0-macos-arm64.dmg` | `DroidDebugHunter-1.1.0-macos-arm64.tar.gz` |
| macOS Intel | `DroidDebugHunter-1.1.0-macos-x64.dmg` | `DroidDebugHunter-1.1.0-macos-x64.tar.gz` |
| Linux x86-64 | `DroidDebugHunter-1.1.0-linux-x64.deb` | `DroidDebugHunter-1.1.0-linux-x64.tar.gz` |

**Системные JDK/JRE не требуются.** Java runtime включён в каждую поставку. JDK нужен только разработчикам при сборке исходников.

## Запуск

- **Windows:** установите MSI либо распакуйте ZIP целиком и запустите `DroidDebugHunterByCompose.exe`. Сохраняйте рядом каталоги `app` и `runtime`.
- **macOS:** выберите архитектуру своего Mac. Откройте DMG и перенесите `.app` в Applications либо распакуйте соответствующий `.tar.gz` целиком.
- **Linux:** установите DEB через системный менеджер пакетов либо распакуйте `.tar.gz` и запустите `./bin/DroidDebugHunterByCompose` из распакованной папки. Нужна графическая среда рабочего стола; системные библиотеки GUI зависят от дистрибутива.

Сборки не подписаны сертификатом издателя. macOS-поставки не прошли notarization; системная проверка безопасности может ограничивать запуск скачанного приложения. Подпись и notarization будут добавлены отдельно.

## Возможности

- USB/Wi-Fi ADB и сопряжение Android 11+.
- Управление приложениями, Android-профилями, процессами и runtime-разрешениями.
- frida-server/Gadget; режимы Proxy, OkHttp, Native TLS и WireGuard VPN.
- Импорт/экспорт HAR, фильтры, отдельные окна деталей, Text/JSON/Image/HEX/Base64 и cURL для PowerShell/sh/bash/zsh.
- Потоковый Logcat, фильтры и TXT/CSV/JSONL.
- Настройка ADB/Python отдельно для каждой ОС/CPU, отмена операций и ограничение памяти.

HAR-просмотр работает сразу. Для устройства и живого захвата откройте **Настройки → Инструменты**: укажите ADB, Python 3.14 и подготовьте нужные компоненты. В эти публичные архивы не включены Android SDK Platform Tools, Python, Frida binaries и WireGuard APK; они скачиваются отдельно по явной команде пользователя. При обычном запуске приложение ничего не скачивает. Для HTTPS/Frida/VPN выполните ручные шаги Android из встроенной справки.

## Проверки и целостность

Сборки соответствуют исходному коммиту тега `v1.1.0` и подготавливаются на четырёх нативных runners. Перед публикацией выполняются Kotlin/Python-тесты и проверка запуска встроенного Java runtime. Тег и релиз создаются после готовности всех установщиков/архивов.

`SHA256SUMS.txt` содержит SHA-256 файлов. `manifest-*.json` фиксируют платформу, архитектуру, исходный commit и состав поставки. В архивах есть `README-FIRST.md` и `THIRD_PARTY_NOTICES.md`.

Лицензия собственного кода пока выбирается владельцем. Уведомления сторонних компонентов: [THIRD_PARTY_NOTICES.md](https://github.com/MaiklGureev/DroidDebugHunterByCompose/blob/v1.1.0/THIRD_PARTY_NOTICES.md).
