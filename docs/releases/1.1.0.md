# DroidDebugHunter 1.1.0

**English** | [Русский](1.1.0.ru.md)

Android debugging with Kotlin + Compose Desktop: ADB, Frida, HTTP(S), HAR and Logcat.

**No system JDK/JRE is required.** Every package includes Java. JDK is only needed to build from source.

## Start

- Windows: install MSI or extract the complete ZIP and run `DroidDebugHunterByCompose.exe`. Keep `app` and `runtime` beside it.
- macOS: choose the matching CPU architecture, open DMG and copy `.app` to Applications, or extract the entire portable archive.
- Linux: install DEB through the package manager, or extract the archive and run `./bin/DroidDebugHunterByCompose`. A graphical desktop and distribution-specific GUI libraries are required.

Builds are unsigned. macOS packages are not notarized; system security checks may restrict launching a downloaded app. Signing/notarization require separate setup.

## Features and tools

USB/Wi-Fi ADB and Android 11+ pairing; Android apps/profiles/processes/permissions; frida-server/Gadget; Proxy, OkHttp, Native TLS and WireGuard VPN capture; HAR import/export, body viewing and shell-specific cURL; streaming Logcat with TXT/CSV/JSONL export; per-platform tool paths and cancellable operations with memory limits.

HAR analysis works immediately. For devices/live capture, configure ADB and Python 3.14 in Settings → Tools (`Настройки → Инструменты`) and prepare the required components. Public archives exclude Platform Tools, a Python interpreter, Frida binaries and WireGuard APK. Downloads require an explicit action; normal startup downloads nothing. Follow offline Help for Android CA/Frida/VPN steps.
