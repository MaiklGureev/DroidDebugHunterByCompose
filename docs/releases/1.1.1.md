# DroidDebugHunter 1.1.1

**English** | [Русская документация / Release notes in Russian](https://github.com/MaiklGureev/DroidDebugHunterByCompose/blob/v1.1.1/docs/releases/1.1.1.ru.md)

This patch release includes the latest development-launch fix, the MIT License and English/Russian documentation. Native packages include Java: **no system JDK/JRE is required**.

## Changes since 1.1.0

- Fixed `NoClassDefFoundError` for lazily loaded coroutine classes when rebuilding an app launched from IDEA/Gradle. The `desktop` / `run` configuration uses a separate temporary JAR that remains stable until the process exits.
- Extended startup checks to exercise device selection and model shutdown on the Swing dispatcher, using isolated temporary data without connecting to Android or touching user settings.
- Added the [MIT License](https://github.com/MaiklGureev/DroidDebugHunterByCompose/blob/v1.1.1/LICENSE) for project-owned code. Third-party components retain their original licenses and notices.
- Made English the default repository documentation language, with a Russian link at the top. Added bilingual platform, architecture, contribution, security and release documentation.
- Updated offline Help for Compose and all three OS families, replacing obsolete WPF/.NET instructions. Eight help topics are available in both English and Russian; the desktop UI still uses Russian labels.
- Included `LICENSE`, `README-FIRST.md`, `README-FIRST.ru.md`, `THIRD_PARTY_NOTICES.md` and `THIRD_PARTY_NOTICES.ru.md` in portable archives and as separate release downloads. Full offline guides are bundled inside the application.

- **Windows:** install MSI, or extract the complete ZIP and run `DroidDebugHunterByCompose.exe`. Keep `app` and `runtime` beside the executable.
- **macOS:** choose the matching CPU architecture, copy the `.app` from DMG to Applications, or extract the complete portable archive.
- **Linux:** install DEB through the package manager, or extract the portable archive and run `./bin/DroidDebugHunterByCompose`. A graphical desktop is required.

Current builds are unsigned; macOS packages are not notarized. System security checks may restrict launching a downloaded application.

HAR analysis works immediately. For devices/live capture, configure ADB and Python 3.14 in Settings → Tools (`Настройки → Инструменты`) and explicitly prepare the required components. Public packages do not include an external Python interpreter, ADB, Frida binaries or WireGuard APK. Normal startup downloads nothing. Follow offline Help for CA trust, Frida and Android VPN consent.

## Validation and integrity

Four native CI runners build/test Windows x64, Linux x64, macOS arm64 and macOS x64. Validation covers Kotlin/Python tests, private-runtime startup, device selection and shutdown. A separate CI check verifies the isolated development JAR.

Publication verifies all eight binaries against their source commit, version, size and SHA-256 before creating the release. `SHA256SUMS.txt` covers the release assets; `manifest-*.json` records platform, architecture and exact source commit. All packages are built from the commit tagged `v1.1.1`.
