# DroidDebugHunter 1.1.4

[English](https://github.com/MaiklGureev/DroidDebugHunterByCompose/blob/v1.1.4/docs/releases/1.1.4.md) · **Русский**

## Изменения

- **Захват одного приложения через WireGuard.** Профиль VPN направляет в туннель трафик выбранного пакета. При проверке на TECNO по USB захвачено семь HTTP-запросов «Навигатора». Контрольный запрос из Chrome дошёл до тестового сервера напрямую. В захвате запросов Chrome было ноль.
- **Область захвата видна на вкладке «Трафик».** Системный HTTP(S)-прокси работает для всего устройства. С вкладки можно перейти к настройке WireGuard. В режимах WireGuard и Frida по умолчанию включён фильтр **«Только выбранное приложение»**. После передачи профиля приложение открывает WireGuard через найденную Android-активность запуска.
- **Настройка подключения.** USB, Wi-Fi, эмулятор, требования выбранного способа захвата и настройки утилит сгруппированы на вкладке «Подключение». Для каждой утилиты отображаются обнаруженная версия, версия для скачивания и доступные способы установки.
- **Совместимость утилит.** Архивы ADB проверяются по архитектуре компьютера. На Linux ARM64 можно указать нативный ADB из дистрибутива или выбрать совместимый локальный архив. Прокси на Intel Mac поддерживает установку из локального wheel `cryptography`.
- **Диагностика.** Приложение записывает версию, параметры запуска и ошибки вызовов утилит в файл. Журнал можно выгрузить или очистить в настройках.
- **Офлайн-справка.** Кнопка «Назад» возвращает к правильному Markdown-документу, даже если файл был открыт через альтернативный путь в Windows или macOS.
