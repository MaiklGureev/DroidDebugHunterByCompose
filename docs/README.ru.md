Собственный код и документация распространяются по [MIT](../LICENSE). Сторонние лицензии сохраняются. Основной язык репозитория — английский; у каждого руководства есть русская версия. Встроенная справка сохраняет русские имена файлов, используемые интерфейсом, и содержит английские версии `.en.md`. Оба языка доступны офлайн из папки справки. В интерфейсе можно выбрать русский или английский через «Настройки → Язык интерфейса». Выбор применяется сразу и сохраняется автоматически; справка следует этому выбору.
