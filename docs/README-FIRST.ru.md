# DroidDebugHunter — первый запуск

[English](README-FIRST.md) | **Русский**

Java уже включена в приложение. Устанавливать JDK/JRE в систему не требуется.

- Windows: распакуйте весь ZIP и запустите `DroidDebugHunterByCompose.exe`. Каталоги `app` и `runtime` должны оставаться рядом с exe. Либо используйте MSI.
- macOS: откройте `.app` из распакованной папки либо перенесите его из DMG в Applications. Архитектура arm64 — для Apple Silicon, x64 — для Intel. Сборка пока без подписи издателя и notarization.
- Linux x64: запустите `./bin/DroidDebugHunterByCompose` в распакованной папке либо установите DEB. Требуется графическая среда рабочего стола.

HAR-просмотр доступен сразу. Файл для знакомства: [examples/sample.har](https://github.com/MaiklGureev/DroidDebugHunterByCompose/blob/v1.1.3/examples/sample.har).

Для работы с телефоном откройте **Настройки → Инструменты** и выберите доступную для записи папку. Открытые карточки предлагают ручной, полуавтоматический и автоматический режимы. Выберите компонент или комплект Frida, затем при необходимости способ установки Python. Переносимый uv подготавливает Python без системного интерпретатора; доступны существующий Python/venv и офлайн-файлы. Загрузка запускается только по нажатию кнопки, с прогрессом, живым журналом и отменой. Мастер не запрашивает повышение привилегий и не меняет системный PATH.

Проверьте обнаруженные версии относительно целевых; другие версии разрешены с предупреждениями о совместимости. **«Ссылки загрузки / папки»** содержит отдельные загрузки архивов, копирование ссылок и инструкции размещения. Недостающие каталоги создаются при запуске, если есть доступ; **«Структура папок»** показывает схему ручной настройки. Полное [руководство по инструментам](https://github.com/MaiklGureev/DroidDebugHunterByCompose/blob/v1.1.3/src/main/resources/runtime/help/DOWNLOADS.md) также входит во встроенную справку. Публичные архивы не содержат отдельный Python, ADB, серверы Frida или APK WireGuard.

USB-отладку, доверие сертификатам и разрешение VPN подтверждают на Android. Для выбора режима и подготовки используйте значок настройки на экране «Трафик» и встроенную справку.

Справка включена на русском и английском и извлекается в `runtime/help` пользовательского каталога данных. Русский/английский переключаются через «Настройки → Язык интерфейса» сразу и с автоматическим сохранением. Справка следует выбранному языку.
